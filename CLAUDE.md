# Сайт косметолога (ИП). Next.js App Router + TS + Tailwind v4.

## Дизайн (соблюдать строго)
- Эстетика: чистая, лаконичная, много воздуха. Премиально-спокойно, без глянца.
- Палитра — пастель, красно-зелёная. Токены в globals.css:
  coral (тёплый красный) = основная кнопка/CTA; sage (зелёный) = второй акцент.
  Красный и зелёный равноправны, НЕ как светофор. Фон cream, текст ink (не чёрный).
- Скругления 12–16px, тени деликатные, разделители тонкие (--color-line).
- Заголовки крупные, межстрочный щедрый. Шрифт Manrope.
- Никаких сторонних UI-китов. Только Tailwind-классы через токены (bg-coral, text-ink).

## Структура
- Компоненты: components/ (Header, Footer, Button, Card, ServiceCard, InfoTable, CookieBanner, A11yToggle).
- Каждая страница = app/<route>/page.tsx. Метаданные через export const metadata.
- Документы PDF: /public/docs. Картинки: /public/images (next/image, webp).
- Контент инфо-страниц выносить в data/ (TS-объекты), не хардкодить в разметке.
- Юр. данные (ОГРНИП, лицензия и т.п.) НЕ выдумывать — плейсхолдеры {{...}} + // TODO.

## Обязательно на КАЖДОЙ странице
- Header с навигацией + A11yToggle. Footer с дисклеймером «О возможных
  противопоказаниях проконсультируйтесь со специалистом» + телефон.
- CookieBanner один раз на layout. Версия для слабовидящих обязательна (закон).

## Юридический контекст
Контент медорганизации регулируется Приказом Минздрава №118н (с 01.09.2025),
ПП РФ №736 (платные услуги), ст.79.1 ФЗ-323. Это ИП в одно лицо (НЕ ООО):
вместо ОГРН → ОГРНИП; нет учредителей и КПП; «структура управления» = сама ИП.
Косметология платная, без ОМС. Названия услуг — по номенклатуре №804н.

## Что обязано быть на инфо-страницах (по 118н)
- /about — наименование (полное+сокр.), адрес местонахождения и почтовый, схема
  проезда, ОГРНИП, ИНН, режим работы, телефоны, email, график приёма граждан,
  структура управления (для ИП — кратко: руководитель = ИП).
- /license — дата выдачи, рег. номер лицензии, QR-код / выписка из реестра
  лицензий (НЕ простой скан — скан лицензии больше не требование).
- /specialist — ФИО; должность по номенклатуре; образование (уровень,
  организация, год, специальность, квалификация); ординатура/переподготовка;
  аккредитация (специальность + срок) или сертификат; график и часы приёма.
- /medical-info — виды мед. помощи; правила записи на первичный приём;
  подготовка к процедурам; блок о госгарантиях (формулировка: услуги платные,
  в программе госгарантий не участвует) + ссылка на федеральную программу.
- /paid-services — Правила платных услуг (ПП 736); перечень услуг; цены;
  прайс отдельным PDF (утверждён, с подписью/печатью); сроки ожидания;
  памятка о налоговом вычете и порядке оплаты.
- /patient-rights — права и обязанности граждан в сфере охраны здоровья;
  правила поведения пациента (ПП 736).
- /supervisory — адреса и телефоны ТЕРРИТОРИАЛЬНЫХ Росздравнадзора и
  Роспотребнадзора. ⚠️ Региональный Минздрав НЕ указывать (частников не контролирует).
- /vacancies — вакантные должности (если нет — раздел с пометкой об отсутствии) (их нет).
- /legal — политика обработки ПД, согласие на обработку ПД, согласие на рассылки,
  политика и согласие на cookie, пользовательское соглашение. Всё — <a download> на PDF.
